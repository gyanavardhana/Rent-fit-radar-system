# Rent Fit Radar Resources

## Knowledge

- [Sarvam AI: Developer Quickstart](https://docs.sarvam.ai/api/getting-started/quickstart)
  Official setup and first-call guide. Use for authentication, SDK setup, and the STT/TTS/translation capability map.
- [Sarvam AI: Text-to-Speech guide](https://docs.sarvam.ai/api/guides/text-to-speech/overview)
  Official reference point for selecting voice output behaviour and handling audio in the app.
- [Anakin: POST Search](https://anakin.io/docs/api-reference/search/search)
  Official contract for the synchronous search endpoint, including request fields and returned title, URL, and snippet evidence.
- [Anakin: Getting Started](https://anakin.io/docs/documentation/getting-started)
  Official orientation to the scraper/search product surface and API-key setup.
- [Rent Fit Radar MVP Specification](./RENT_FIT_RADAR_SPEC.md)
  Project-specific source of truth for scope, user flow, interfaces, errors, and demo criteria.

## Wisdom (Communities)

- [Sarvam AI Discord](https://discord.com/invite/sarvam-ai)
  Use for SDK or model-behaviour questions that are not resolved by the official docs.
- [Anakin Community](https://anakin.io/community)
  Use for implementation questions and practical scraping/search patterns.

## Gaps

- Exact, trustworthy live commute-time data is intentionally out of scope for the MVP. The project should describe commute as a contextual trade-off, not a guaranteed ETA.
