# Mission: Ship and explain Rent Fit Radar

## Why

Build a credible AI Engineer Mixer demo that helps Bengaluru renters choose a locality from their budget, home needs, commute, and nearby-life priorities. Develop practical fluency with voice input/output and live-web retrieval so the implementation can be built, debugged, and clearly explained under sprint conditions.

## Success looks like

- Explain the end-to-end request path and why secrets never reach the browser.
- Build a server route that turns renter preferences into source-backed locality evidence and a ranked recommendation.
- Add a useful Sarvam voice layer without making it a fragile dependency for the core result.
- Demo the application and accurately describe where Sarvam and Anakin add value.

## Constraints

- Full-stack developer; skip generic frontend, backend, cloud, and DevOps fundamentals.
- 90-minute sprint scope; prefer one reliable vertical slice over broad coverage.
- Learn through short, practical lessons tied to the current project.

## Out of scope

- Production-grade geospatial routing, individual property-booking flows, and multi-turn real-time voice conversations.
